RetroDir 1.0.1 LATEST October 2026

Fixed

  • Cmd-T from a panel now opens the terminal in that panel's current folder. Before, it always brought back the first terminal tab in whatever folder it started in. If a tab is already in that folder, RetroDir switches to it; otherwise it opens a new tab there. Shells that are busy (an ssh session, an editor) are never changed.
  • The About box now shows the correct version number.

RetroDir 1.0 October 16, 2026

The first public release.

Highlights

  • Two side-by-side panels with function-key file operations: view, edit, copy, rename or move, make folder, and move to Trash (F3–F8).
  • A built-in terminal in a bottom split (Cmd-T) with tabs, resizing, and syncing folders between the shell and the panels.
  • A viewer with hex mode, wrap, go-to and search, and an editor with undo, search and replace.
  • Quick View (Ctrl-Q) and Info (Ctrl-L) panels, archives (zip and tar), find files, folder hotlist and history.
  • Four colour themes: Classic Blue, Midnight, Amber and Navy.
  • Mac touches: Trash, Quick Look, Finder drag and drop, APFS clones for fast copies, and Cmd-1…Cmd-0 as F-keys on laptops.
